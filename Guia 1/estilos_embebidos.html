Estilos embebidos en las etiquetas HTML

Usar estilos CSS embebidos en las etiquetas HTML es el peor y menos utilizado de los métodos para agregar reglas de estilo. No es nada recomendable por la dificultad que implica realizar un cambio posteriori.

Esta froma de incluir CSS directamente en los elementos HTML solamente se utiliza en determinadas situaciones en las que se debe incluir un estilo muy especifico para un solo elemnto concreto.

Para insertar un estilo CSS en un elemento se utiliza la propiedad style de HTML, que en ningun momento debe confundir con la etiqueta <style< que se introduce en la cabecera del documento.
